Pro Graph Code Builder

A precision mathematics IDE designed specifically for graph theory, matrix analysis, and academic publishing. Visually construct complex graphs and instantly generate publication-ready LaTeX code in both TikZ and PSTricks formats.

⌨️ Keyboard Shortcuts

  • Shift + Click: Select multiple items at once to edit or move them together.
  • Ctrl + A (or Cmd+A): Select all elements on the canvas.
  • Ctrl + Z / Ctrl + Y: Undo and Redo.
  • Delete or Backspace: Erase selected items.

✨ Key Features

  • Live LaTeX Rendering: All text and node labels automatically render standard LaTeX math (e.g., \lambda_{max}) on the canvas.
  • Graph Macros: Instantly generate perfectly symmetrical Complete Graphs, Cycles, Paths, Stars, and Bipartite Graphs via the Macros toolbar.
  • Precision Snapping: Vertices snap to grid intersections or align automatically with other nodes while dragging.
  • Smart Edges: Draw lines, circles, arcs, and bezier curves (perfect for parallel edges and self-loops). Set labels to break the line dynamically using the "On Line" position.

🖱️ How to Use

  1. Draw: Select a drawing tool (Point, Line, Curve) and click the canvas. The tools are continuous, so you can rapidly build networks.
  2. Edit: Switch to the `Select` tool (Arrow) and click any item to reveal its specific inputs in the Properties Panel.
  3. Export: The right panel automatically updates with your LaTeX code. Select TikZ or PSTricks, copy, and paste directly into your document!
