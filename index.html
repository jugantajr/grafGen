timeline Pro Graph Code Builder

A precision mathematics IDE designed specifically for graph theory, matrix analysis, and academic publishing. Visually construct complex graphs and instantly generate publication-ready LaTeX code.

🛠️ Drawing Tools

  • radio_button_checked Point: Click the canvas to drop nodes.
  • timeline Line: Click two points sequentially to connect them.
  • gesture Curve: Click two points to draw a bezier curve.
  • radio_button_unchecked Circle: Click one point to create a circle.
  • incomplete_circle Arc: Click one point to create an open arc.
  • toll Elliptic Arc: Click two points to set the foci.
  • highlight_alt Region: Drag a box to draw a cluster highlight background.
  • text_fields Free Text: Click anywhere to add LaTeX math text.

🖱️ Actions & System

  • arrow_selector_tool Select: Click items to edit. Hold Shift for multi-select.
  • pan_tool Move: Drag items or drag empty canvas to pan.
  • ink_eraser Eraser: Click any item to instantly delete it.
  • undo / redo Undo & Redo: Step backward or forward.
  • swap_vert Layout: Toggle vertical/horizontal panel split.
  • image Export Image: Download transparent PNG.

⌨️ Keyboard Shortcuts

  • Ctrl + A: Select all elements.
  • Ctrl + Z / Y: Undo / Redo.
  • Delete: Erase currently selected items.

💡 Pro Tip for Edge Labels: In the properties panel, change the Pos: dropdown to "On Line" to draw text with a white background directly over an edge (standard LaTeX convention), or use "Above/Below/Left/Right" for exact offset positioning.
