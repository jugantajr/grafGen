timeline grafGen: Complete Guide

Welcome to grafGen. This IDE generates publication-ready LaTeX code, Adjacency/Laplacian matrices, and Python/SageMath scripts directly from your visual layout.

(Replace 'demo.gif' in your project folder with your screen recording)

🛠️ Drawing Tools & Hotkeys

  • radio_button_checked P Point: Click canvas to drop nodes.
  • timeline L Line: Click two points to connect them.
  • gesture C Curve: Connect two points (adjust offset in Properties).
  • all_inclusive Loop: Click a single point to add a self-loop.
  • radio_button_unchecked Circle: Click one point to create a boundary circle.
  • incomplete_circle Arc: Click one point (adjust angles in Properties).
  • toll Elliptic Arc: Click two points to set the foci.
  • highlight_alt Region: Drag a box to draw a shaded cluster.
  • text_fields Text: Click anywhere to add free-floating LaTeX math.

🖱️ Interactive Tools

  • arrow_selector_tool S Select: Click to edit items. Hold Shift for multi-select.
  • polyline Lasso: Draw a freehand circle to grab multiple nodes.
  • format_color_fill F Paint Bucket: Click any item to dye it the active color.
  • pan_tool M Move: Drag selected items, or drag empty space to pan.
  • ink_eraser Del Eraser: Click items to delete. (Or press 'Delete' key).
  • mouse Right-Click Menu: Right-click any node or selected cluster to instantly open the Quick Edit color/delete menu.

📈 XY Plot Table Examples

  • Chart types: Use the plot type dropdown to switch between line, scatter, bar, and step previews.
  • CSV import: Use Import CSV to load a `.csv` or `.txt` table into the plot editor.
  • One x column, many y series: Use one shared x column and one column per series. 
    x, y1, y2
0, 1, 2
1, 3, 4
2, 5, 8
  • Several x-y plots in one table: Use column pairs like x1, y1, x2, y2, then fill the rows. 
    x1, y1, x2, y2
0, 1, 0, 2
1, 3, 1, 4
2, 5, 2, 8
  • Use commas, spaces, or semicolons as separators. The first row is treated as labels.
  • The plot preview supports grid and legend toggles, and the generated code can be copied as Matplotlib, PGFPlots, or Gnuplot.

✨ Macros & Generation

  • Kn / Cn / Pn / Star: Instantly spawn Complete graphs, Cycles, Paths, and Stars.
  • Km,n (Bipartite): Generates complete bipartite layouts.
  • Grid: Generates a perfect $m \times n$ rectangular lattice.
  • Q3 (Hypercube): Spawns a 3D projected hypercube.
  • auto_fix_high Magic Untangle: Uses spring-physics to physically repel nodes and untangle messy crossing edges.
  • palette Auto-Color: Uses a greedy algorithm to instantly color the graph without adjacent nodes sharing a color.
  • call_split Bipartite Snapper: Tests if the graph is bipartite. If yes, it physically snaps into two colored sets. If no, it highlights the odd-length cycle in red.

📊 Mathematical Analysis

  • |V| & |E|: Real-time counting of Order and Size.
  • Spec(A): Calculates and displays the spectrum (eigenvalues) of the Adjacency Matrix in real-time.
  • Invisible Nodes (Wireframes): Select a node and set its Radius to 0. It becomes invisible on the canvas and exports as a hidden coordinate in LaTeX, allowing you to draw pure architectural wireframes!

💾 Output & Export

  • TikZ / PSTricks: Standard LaTeX graphics packages.
  • XY Plot Table: Paste a small CSV-like table, choose a mode, then click Render Plot to preview the chart and generate Matplotlib code.
  • Matrices: Auto-maps nodes to formulate the Adjacency ($A$), Degree ($D$), and Laplacian ($L$) matrices in LaTeX.
  • Code/Scripts: Outputs ready-to-run edge lists for Python (NetworkX), SageMath, Mathematica, and MATLAB.
  • Image: Download a transparent, print-ready PNG (automatically handles dark/light mode inversion).
Pro Tips: Use Ctrl+A to select all items. Ctrl+Z / Ctrl+Y to Undo/Redo. Use the content_copy Copy Button to instantly grab your generated code!
