timeline grafGen: Complete Guide

Welcome to grafGen. This IDE generates publication-ready LaTeX code, Adjacency/Laplacian matrices, and Python scripts directly from your visual layout.

🛠️ Drawing Tools

  • radio_button_checked Point: Click canvas to drop nodes.
  • timeline Line: Click two points to connect them.
  • gesture Curve: Connect two points (adjust offset in Properties).
  • all_inclusive Loop: Click a single point to add a self-loop.
  • radio_button_unchecked Circle: Click one point to create a boundary circle.
  • incomplete_circle Arc: Click one point (adjust angles in Properties).
  • toll Elliptic Arc: Click two points to set the foci.
  • highlight_alt Region: Drag a box to draw a shaded cluster.
  • text_fields Text: Click anywhere to add free-floating LaTeX math.

🖱️ Interactive Tools

  • arrow_selector_tool Select: Click to edit items. Hold Shift for multi-select.
  • polyline Lasso: Draw a freehand circle to grab multiple nodes.
  • format_color_fill Paint Bucket: Click any item to dye it the active color.
  • pan_tool Move: Drag selected items, or drag empty space to pan.
  • ink_eraser Eraser: Click items to delete. (Or press 'Delete' key).

✨ Macros & Generation

  • Kn / Cn / Pn / Star: Instantly spawn Complete graphs, Cycles, Paths, and Stars with $n$ nodes.
  • Km,n (Bipartite): Generates complete bipartite layouts.
  • Grid: Generates a perfect $m \times n$ rectangular lattice.
  • Q3 (Hypercube): Spawns a 3D projected hypercube.
  • auto_fix_high Magic Untangle: Uses spring-physics to physically repel nodes and untangle messy crossing edges.
  • palette Auto-Color: Uses a greedy algorithm to instantly color the graph without adjacent nodes sharing a color.
  • call_split Bipartite Snapper: Tests if the graph is bipartite. If yes, it physically snaps into two colored sets. If no, it highlights the odd-length cycle in red.

📊 Mathematical HUD

  • |V| & |E|: Real-time counting of Order and Size.
  • d(v): Click a single vertex to see its exact degree.
  • Spec(A): Live calculation of the Adjacency Matrix eigenvalues ($\lambda_1 \dots \lambda_n$). Supports complex roots for directed graphs.

💾 Output & Export

  • TikZ / PSTricks: Standard LaTeX graphics packages.
  • Matrices: Auto-maps nodes to formulate the Adjacency ($A$), Degree ($D$), and Laplacian ($L$) matrices in LaTeX.
  • Python (NetworkX): Outputs raw Python code to recreate the exact visual graph programmatically.
  • Image / JSON: Download transparent PNGs or save/load your project workspace geometry.
Pro Tips: Use Ctrl+A to select all items. Ctrl+Z / Ctrl+Y to Undo/Redo. The Dark Mode (dark_mode) toggle uses smart CSS inversion, so your transparent PNG exports will still be print-ready (black ink) even if drawn in night mode!
